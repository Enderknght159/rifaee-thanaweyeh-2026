# معاً نُكمل المسيرة — ثانوية الشيخ عبد الكريم الرفاعي الشرعية

عرض شرائح ثابت (HTML/CSS/JS) باللغة العربية واتجاه RTL، أُعدّ لدعم ثانوية الشيخ عبد الكريم الرفاعي الشرعية والتعريف بمسيرتها وخطة نهضتها. يتكوّن العرض من 17 مشهداً ينتقل بينها تلقائياً، ولا يحتوي على أي صوت أو موسيقى؛ الصور والنصوص فقط.

## عرض اجتماع أولياء الأمور

عرض إنفوغرافيكس بخطوط كبيرة، بلا صور عدا واجهة الثانوية على شريحة الغلاف مع تعتيم قوي من الهوية البصرية. شرائحه:

1. الغلاف: أولياء الأمور شركاء المسيرة.
2. جدول أعمال اللقاء.
3. افتتاح الاجتماع — تلاوة القرآن، أ. أنس صياد.
4. كلمة عريف الاجتماع، أ. فهمي قصقص.
5. كلمة إدارة الثانوية، أ. معاذ نعمان.
6. كلمة التوجيه التربوي.
7. مداخلة الرياضيات، أ. أحمد غراء.
8. مداخلة الاجتماعيات، أ. ضياء الدين مارديني.
9. لقاء المدرسين في الصفوف.
10. الختام والدعوة إلى المساهمة.

**ملء الفراغ:** زر «العرض» في شريط التحكم — أو زر الشريحة الأخيرة — يفتح عرض الإنجاز والتبرع داخل نافذة فوق الاجتماع، دون فقدان الشريحة الحالية. زر **العودة إلى الاجتماع** داخل النافذة (أو Esc) يرجعك إلى الشريحة نفسها التي كنت عليها.

**الفهرس:** زر «الفهرس» في الشريط العلوي، أو مفتاح I، يعرض قائمة الشرائح مع الموضع الحالي.

**التحكم:** الأسهم للتنقل، مسافة/النقر للتالي، `D` لعرض الإنجاز، `I` للفهرس، `F` لملء الشاشة، `Home/End` لأول/آخر شريحة.

## التشغيل محلياً

من داخل مجلد المشروع:

```bash
python -m http.server 8765
```

ثم افتح في المتصفح:

```
http://localhost:8765/
```

وجود خادم محلي ضروري لأن العرض يحمّل الخطوط والصور من مسارات نسبية.

## التحكم

- **تشغيل تلقائي:** يبدأ العرض تلقائياً ويتنقل بين المشاهد وفق مدة كل مشهد، ثم يعيد التدوير.
- **مسافة (Space) أو النقر على الشاشة:** إيقاف/استئناف التشغيل التلقائي.
- **السهم الأيسر:** المشهد التالي. **السهم الأيمن:** المشهد السابق.
- **Home / End:** أول مشهد / آخر مشهد.
- **F:** تفعيل/إلغاء وضع ملء الشاشة.
- **زر شريط التحكم:** تشغيل/إيقاف، السابق، التالي، ملء الشاشة.
- **رابط مباشر لمشهد:** أضف `?s=رقم` إلى العنوان، مثل `?s=7`.

## ملاحظات

- لا يوجد صوت في العرض؛ لا ملفات صوتية ولا موسيقى ولا تعليق صوتي.
- الصور الفوتوغرافية ملك للثانوية، وخطوط الهوية مأخوذة من أدوات الهوية البصرية الخاصة بها، وخط الآية **Uthmanic Hafs** من صفحة القرآن المرجعية (quran.com).
- الآية القرآنية مكتوبة بالرسم العثماني بخط **Uthmanic Hafs** (الخط العثماني المستخدم في صفحة القرآن المرجعية)، ويُستخدم Amiri Quran خطاً احتياطياً.
