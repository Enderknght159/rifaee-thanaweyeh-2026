# معاً نُكمل المسيرة — ثانوية الشيخ عبد الكريم الرفاعي الشرعية

عرض شرائح ثابت (HTML/CSS/JS) باللغة العربية واتجاه RTL، أُعدّ لدعم ثانوية الشيخ عبد الكريم الرفاعي الشرعية والتعريف بمسيرتها وخطة نهضتها. يتكوّن العرض من 17 مشهداً ينتقل بينها تلقائياً، ولا يحتوي على أي صوت أو موسيقى؛ الصور والنصوص فقط.

## التشغيل محلياً

من داخل مجلد المشروع:

```bash
python -m http.server 8765
```

ثم افتح في المتصفح:

```
http://localhost:8765/
```

وجود خادم محلي ضروري لأن العرض يحمّل الخطوط والصور من مسارات نسبية.

## التحكم

- **تشغيل تلقائي:** يبدأ العرض تلقائياً ويتنقل بين المشاهد وفق مدة كل مشهد، ثم يعيد التدوير.
- **مسافة (Space) أو النقر على الشاشة:** إيقاف/استئناف التشغيل التلقائي.
- **السهم الأيسر:** المشهد التالي. **السهم الأيمن:** المشهد السابق.
- **Home / End:** أول مشهد / آخر مشهد.
- **F:** تفعيل/إلغاء وضع ملء الشاشة.
- **زر شريط التحكم:** تشغيل/إيقاف، السابق، التالي، ملء الشاشة.
- **رابط مباشر لمشهد:** أضف `?s=رقم` إلى العنوان، مثل `?s=7`.

## خريطة الملفات

| المسار | الوصف |
| --- | --- |
| `index.html` | نسخة مطابقة بالبايت من ملف العرض، يستخدمها GitHub Pages من جذر الموقع. |
| `عرض-معا-نكمل-المسيرة.html` | ملف العرض الأصلي. |
| `assets/css/deck.css` | تنسيقات العرض والخطوط والحركات. |
| `assets/js/deck.js` | محرك العرض: التنقل، المؤقت، ملء الشاشة، التحميل المسبق. |
| `assets/media/m01.jpg` … `m29.jpg` | الصور المستخدمة في المشاهد (29 صورة). |
| `assets/media/map.json` | بيانات وصفية للصور. |
| `assets/brand/` | شعار الثانوية (ملون وأبيض) ونمط النجمة. |
| `assets/fonts/` | خطوط الهوية: HacenAlgeria وHacenAlgeria-Bold وHacenAlgeriaHD، وخط AmiriQuran-Arabic.woff2 للآية القرآنية. |
| `assets/images/` | صور خام أصلية محفوظة في المشروع وغير مستخدمة مباشرة في العرض. |

## ملاحظات

- لا يوجد صوت في العرض؛ لا ملفات صوتية ولا موسيقى ولا تعليق صوتي.
- الصور الفوتوغرافية ملك للثانوية، والخطوط مأخوذة من أدوات الهوية البصرية الخاصة بها.
- الآية القرآنية مكتوبة بخط **Amiri Quran**.
